💳 3. Como Testar

Passos para Teste Completo:
1. Abra Lista de Cartões: Lista-de-cartoes.html
2. Clique em um cartão → Deve levar para despesas daquele cartão
3. Verifique o título → Deve mostrar o nome do cartão
4. Verifique URL → Deve ter ?cartao=ID&nome=NOME
5. Crie uma nova despesa → Nova despesa no cartão
6. Volte para lista → Despesa deve aparecer filtrada por cartão

🐛 4. Verificações Técnicas

Console Debug: Abra F12 → Console para ver logs detalhados:
• "📱 Cartão selecionado: NOME ID: ID"
• "🔍 Filtrado para cartão: NOME (ID)"
• "Despesas de cartão carregadas: [array]"

🔧 6. Solução de Problemas

Se não carregar despesas:
• Verifique se despesas foram salvas com tipo='cartao'
• Verifique se o campo 'conta' corresponde ao ID do cartão
• Abra Console (F12) para ver logs de debug
• Verifique se está autenticado no Firebase
